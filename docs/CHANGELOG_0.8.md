# Zmiany 0.6.1 → 0.8

- 0.6.1: grupowanie albumów bez rozróżniania wielkości liter i nadmiarowych odstępów, również w Android Auto. Bez migracji plików i utraty polubień.
- Rozszerzenie sieciowe: wybór AirPlay i DLNA na Windows/Android; Yamaha/MusicCast przez DLNA i wybudzanie YXC. Parowanie HAP/PIN, oryginalne pliki DLNA i Sinc SRC do 44,1 kHz przy AirPlay.
- 0.7: kreator Audio CD na PC, odczyt TOC i Disc ID, wybór MusicBrainz, powtarzane odczyty, FLAC i raport błędów.
- 0.8: wejścia audio, kontrola poziomu i przesterowania, nagrania stron A/B, pełny WAV, odzyskanie po awarii, znaczniki/cisza i eksport opisanych FLAC.

Wersja testowa. Otwarte kryteria sprzętowe i ograniczenia są opisane w README i TESTY_0.8.md. Nie zmieniamy statusów historycznych testów na podstawie samej kompilacji.
