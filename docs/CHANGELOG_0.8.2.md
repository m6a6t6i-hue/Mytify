# Mytify 0.8.2 — odtwarzacz na górze telefonu

- Na telefonie duża karta z okładką, play/pause i paskiem postępu jest pierwszą sekcją pod wyszukiwarką.
- Nagłówek, licznik kolekcji i przyciski biblioteki przeniesiono pod odtwarzacz.
- Start wraca do początku strony także po przewinięciu. Mały pasek wraca wcześniej podczas przeglądania dalszych sekcji.
- Kolejność sekcji na PC zachowana. To wydanie dostarcza APK Android i pełny kod źródłowy; binarny Windows pozostaje w wydaniu 0.8.1.
- APK: 0.8.2 (11), ten sam podpis i identyfikator pl.mytify.app. Aktualizacja zachowuje bibliotekę.
